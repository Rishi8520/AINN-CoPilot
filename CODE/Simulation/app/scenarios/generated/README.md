# Runtime Generated Simulation Configurations

This directory is runtime-only. Timeline/full Simulation mode may create
generated INI files here while preparing OMNeT++/Simu5G runs.

Generated INIs in this directory are not committed. Canonical scenario source
templates and configuration remain in `CODE/Simulation/app/scenarios`, while
recorded generated configurations used for tests live with their fixtures under
`CODE/Simulation/fixtures/replay`.
