# Runtime Simulation Results

This directory is runtime-only. Production Simulation code may create scalar,
vector, vector-index, and history files here while running OMNeT++/Simu5G.

Generated outputs in this directory are not committed. Recorded parser and
replay/demo fixtures live under `CODE/Simulation/fixtures/replay` instead.

Any replayed fixture output must be labelled as replayed or recorded, not as a
live simulation result from the current startup.
